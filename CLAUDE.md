# GoActive Bucharest website

Static site for an informal youth group (Erasmus+ youth exchanges). Plain HTML, CSS and JS: no build step, no dependencies, no cookies, no analytics. Live on GitHub Pages from `main` at https://goactivebucharest.me (DNS on Cloudflare, registrar Namecheap; `www` redirects to the apex). README.md holds the full hosting, DNS and security notes; read it before touching deployment.

## Layout
- One HTML file per page in the root: `index`, `ideas`, `contact`, `brand`, `privacy`, `cookies`, `404`, and the three team profiles. Header, nav and footer markup is duplicated in every page, so a change to shared chrome must be applied to all of them (`rg` for the snippet first). `404.html` is the exception: reduced header, no nav or footer, and root-absolute asset paths so it also renders for deep URLs.
- The nav holds the home page anchors (What’s an exchange · How it works · Team · FAQ) and the “Share an idea” button; the home page links them as `#exchange` etc., every other page as `index.html#exchange`. Since home v2, `ideas.html` and `brand.html` are not linked from the header or footer, and `contact.html` only from the home Partners band and the 404 page (owner to decide).
- `assets/css/style.css` is the design system: tokens at the top (`--ink`, `--paper`, `--white`, `--blue`, `--lime`, `--coral`, `--text`, fonts, radii `--r-sm`/`--r`/`--r-md`/`--r-lg`, `--wrap`). Add new colours or spacing as tokens, not as literals. The home v2 components sit in one block (`.home-*`, `.collage`, `.strip`, `.xcard`, `.path`, `.nolist`, `.idea-card`, `.tcard`, `.faq--band`, `.partner-box`).
- `assets/css/fonts.css` + `assets/fonts/` are self-hosted Archivo and Inter (woff2 only). Do not add Google Fonts or any third-party asset.
- `assets/js/main.js` handles the mobile menu, reveal animations, count-ups and the three forms (home idea form, ideas, contact). Editable settings sit in the `CONFIG` object at the top. A form with `data-gate` (the home idea form) keeps its submit button `aria-disabled` until the form is valid, and a `[data-echo]` element in the success card repeats the submitted field.
- `sitemap.xml`, `robots.txt`, `site.webmanifest`, `CNAME`, `.nojekyll`, `.well-known/security.txt` must stay. Adding a page means adding it to `sitemap.xml` and linking it from the shared chrome in every page.

## Hard rules
- Every page carries a Content Security Policy meta tag. The one inline script (`document.documentElement.classList.add("js")`) is allowed by a sha256 hash in that CSP, identical across all 10 pages. If that line changes, recompute the hash and update every page, or the animations break. Never add other inline scripts or inline event handlers; put JS in `main.js`.
- Forms post to FormSubmit (`formsubmit.co`); it is the only external domain in the CSP `connect-src` and `form-action`. Any new external service must be added to the CSP in every page and to the privacy and cookie policies first. Every form keeps the honeypot, the POST fallback without JavaScript and a required consent checkbox (the privacy policy relies on consent for idea submissions).
- Keep the head block complete on every page: title, description, canonical, theme-color, Open Graph, twitter card. `og:image` is `assets/logo/og-image.png` (1200x630). `404.html` is `noindex` and carries only title and description.
- Team photos are `assets/img/{daniel,vlad,bianca}.jpg` (4:5 JPEG, cropped from the originals). The JS still shows a monogram if a file is missing; don't remove that fallback.
- Respect `prefers-reduced-motion` (main.js already checks it) and keep keyboard access for the mobile menu (`inert`, `aria-expanded`).
- Language: site copy is English (`lang="en"`, `og:locale` en_GB). Keep the tone: short, direct, youth-facing, no corporate filler.

## Design
"Home v2", 2026-09-26, built from the owner's design handoff `design_handoff_home_v2` on top of the 2026-09-23 system. The tokens in `assets/css/style.css` are the source of truth; update this section when they change. The home page is the reference; the inner pages keep their older components under the v2 header and footer.
- Palette, token → role → hex.
  - `--ink` → text on paper, the facts strip, FAQ band and footer, solid pill buttons → #0A0A10; `--ink-2` → surfaces on ink (inner pages) → #14141C (`--ink-3` #1E1E29 is defined but unused).
  - `--paper` → page ground, the sticky header (88% with a 14px blur), text on ink → #F3F0E7; `--paper-2` → cards on paper → #E8E4D8; `--white` → the idea card, inputs, chips, step numbers → #FFFFFF.
  - `--lime` → the highlight block in the h1, the idea band, fact values and links on ink, the open FAQ sign → #D4FF3F. Lime is never text on paper.
  - `--blue` → the How it works band, hover of solid pills and links on paper, eyebrows on paper and the hero dot (`--halo-blue`), focus ring on paper → #2B36FF.
  - `--coral` → the third exchange card, the ✕ markers, a portrait background, invalid-field borders → #FF5B3A.
  - `--text` → body copy on paper → #3A3942; `--muted` → secondary text on paper → #5F5E68; `--muted-d` → on ink → #A3A2B0. Error text is the literal #B3260B, not a token yet.
- Type: Archivo (variable, 400-900, width 62-125%) for display: `.display` is 900, uppercase, line-height .88-.9; home headings use `font-stretch: 108%` (h1 clamp(2.8rem, 6.6vw, 6.4rem), `.home-h2` clamp(2rem, 4.6vw, 4.2rem), the idea heading clamp(2.2rem, 5.4vw, 5rem)). Inter (400-700) for body at 17px (16px under 600px) and UI at 15-16px, 600 on buttons. Eyebrows (`.eyebrow`): Inter 600, 13px, .14em, uppercase. No type-scale tokens.
- Spacing and radius: `--wrap` 1320px, `--gutter` clamp(20px, 4vw, 48px), `--header-h` 68px (sticky, in the flow). Home sections pad clamp(80px, 10vw, 150px), coloured bands clamp(80px, 10vw, 140px). Every multi-column home layout is `repeat(auto-fit, minmax(min(100%, Npx), 1fr))`, so it stacks on phones without media queries. Radius: `--r-md` 28px for cards and photos, `--r-sm` 18px for the hero chip, 14px inputs, 999px pills; `--r` 22px and `--r-lg` 34px remain on inner pages. Under a 440px-wide collage (phones) a container query widens the ink card and moves the chip to the top left, so the chip never covers the card's button.
- Motion: `--ease` cubic-bezier(.2, .7, .1, 1). Buttons lift 2px and their arrow nudges; section heads use `.reveal`; inner pages keep the marquee, orbs and hero line reveal. Keep the three safeguards: reduced motion in CSS and `main.js`, the footer's "Pause animations" button (WCAG 2.2.2), and the CSS failsafe that shows hidden content after 2.5s without JS.
- Voice: young people aged 13–30 and partner organisations. Short, direct, youth-facing, no corporate filler; "we" for the group, "you" for the reader. Home headings answer the visitor's questions in order: what is this, what is an exchange, can I join, how do I get involved. One label for the main action: "Share an idea", on every page. English only. Banned words: none named yet (owner to add).
- Keep: these are the brand, although the `frontend-design` skill lists some as generic tells: eyebrows (`.eyebrow`, `.kicker`, `.label`); the lime highlight block on one phrase of the h1; the rotated photo collage with the ink "Next exchange" card and the white chip in the hero; the arrow in pill buttons; numbered step circles; middle dots ( · ) in eyebrows and the footer; the `.reveal` scroll fade-up.
- Avoid: colours outside the tokens above; new hex literals where a token exists; paper text on lime or coral; stretching, rotating, recolouring or low-contrast placement of the logo; third-party fonts or embeds.
- References: the handoff's `GoActive Home v2.dc.html` and its README (the owner's copy, not in the repo). Its FAQ answers (fee, under-18 consent, group size) were written for the design and still need the owner's check.
- Tried and rejected: the "Megaphone" redesign (one red #EC3013 on paper and ink, square corners, grayscale photos, Archivo only), built 2026-09-26 and replaced the same day by home v2; it was never merged or pushed, and its local branch was deleted. Earlier: footer wordmark set as outlined Archivo text, replaced by the logo-lettering SVG (0465712); the spinning badge on phones, hidden under 600px (0465712); more than one label for the main action (0465712); the long ideas form, now a quick path (idea, age, e-mail) with optional details (0465712); stat numbers sized by the viewport alone, which overflowed their columns, now capped by column width with `cqi` (767081e).
- Redesign, new page or new page type: present two or three directions first (4-6 named hex values, type pairing, hero concept as an ASCII wireframe, one sentence on the memorable element) and wait for the owner's pick.
- Mechanical check: `design-lint.json` (web-qa `design-lint.mjs`, a ratchet, rebaselined for home v2 on 2026-09-26). The devices under Keep are deliberate: never remove one to satisfy it.

## Working here
- Preview: `.claude/launch.json` serves the repo on port 4174 (`pnpm dlx serve@14 . -l 4174 -n`), or open the HTML file directly. Check: `node ~/.claude/skills/web-qa/scripts/site-check.mjs --base http://localhost:4174/ --root .` and `node ~/.claude/skills/web-qa/scripts/design-lint.mjs --root .`. For a clean site-check, point `--base` at a free port so it serves the folder itself: `serve` strips `.html`, which adds canonical and duplicate-title warnings and a false broken link on the 404 page.
- Before finishing UI changes: check 375 px and 1440 px in a browser, check the console (CSP violations show there), and run the `web-qa` skill before a deploy. Also confirm there is no horizontal scroll from 320 to 375 px (`document.documentElement.scrollWidth` equals the viewport width): a long name in the `.next` block of `vlad-rusu.html` once widened the page and a visual check missed it.
- The site is live, so a push to `main` is a production deploy; GitHub Pages republishes within a minute. Do not commit or push unless asked.
- Renewal dates to keep in mind: domain expires 13 September 2027; `security.txt` Expires must be refreshed before then.
